# crumbs
just another macOS launcher

Launch Crumbs once, then press **Control-Shift-Space** to show or hide the launcher from any app. Click outside or press Escape to dismiss it.

## Tests

With Xcode 27 selected, run `swift test` from the repository root. Swift Testing suites under `Tests/` mirror the app's source folders and run without launching the app. To run one suite, use `swift test --filter ApplicationCatalogTests`.
